### 1. The Kinematic Calculus Core

In physics and calculus, motion variables are bound by derivatives (rates of change) and integrals (accumulation of change) over time ( $t$ ).

| Quantity | Vector Symbol | Definition / Calculus Relationship | Graphical Meaning (On a Plot) |
| --- | --- | --- | --- |
| **Position** | $\vec{r}(t)$  or  $s(t)$ | Baseline spatial coordinate | Current location |
| **Velocity** | $\vec{v}(t)$ | $\frac{d\vec{r}}{dt} = \vec{r}'(t)$ | **Slope** of Position-Time ( $s/t$ ) graph |
| **Acceleration** | $\vec{a}(t)$ | $\frac{d\vec{v}}{dt} = \frac{d^2\vec{r}}{dt^2} = \vec{v}'(t)$ | **Slope** of Velocity-Time ( $v/t$ ) graph |
| **Displacement** | $\Delta s$ | $\int\_{t\_1}^{t\_2} v(t) \, dt$ | **Area under** Velocity-Time ( $v/t$ ) graph |
| **Change in Velocity** | $\Delta v$ | $\int\_{t\_1}^{t\_2} a(t) \, dt$ | **Area under** Acceleration-Time ( $a/t$ ) graph |

### 2. Geometric & Vector Abbreviations

Standard notation shortcuts used to compress spatial, vector, and calculus operations in geometric physics:

* **$\vec{r}$**  : Position vector (typically  $[x, y, z]^T$ ).
* **$\hat{u}, \hat{n}, \hat{\tau}$**  : Unit vectors ( $\^{u}$  for general direction, \hat{\n} for normal/perpendicular,  $\^{\tau }$  for tangential).
* **$\dot{x}, \ddot{x}$**  : **Newton's dot notation** for time derivatives ( $\dot{x} = \frac{dx}{dt}$ ,  $\ddot{x} = \frac{d^2x}{dt^2}$ ). Highly common shorthand in kinematics.
* **$s, \theta$**  : Arc length ( $s$ ) and angular position ( $\theta $ ) used in rotational or curvilinear paths.
* **$\omega, \alpha$**  : Angular velocity ( $\omega = \dot{\theta}$ ) and angular acceleration ( $\alpha = \dot{\omega} = \ddot{\theta}$ ).
* **$\nabla $  (Nabla)** : Gradient operator, used if moving into multi-dimensional kinematic fields (e.g., potential energy gradients).
* **$\vec{a}\_c, \vec{a}\_t$**  : Centripetal acceleration ( $v^2/r$  pointing normal to motion) and Tangential acceleration ( $\.{v}$  pointing along motion).
