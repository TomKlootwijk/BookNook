Here is how **Spatial Anchors** and **ARCore Cloud Anchors** work, and how they relate to your memory terms:

### 1. Spatial Anchors (The Broad Concept)

A **Spatial Anchor** is a general industry term for a "digital bookmark" tied to a specific point in the physical world. 

![](../assets/94f7c693955dcc24b6f2.png)Medium·Dean Giddy +1

* **The "Memory" aspect:** When an AR headset or phone looks at a room, it uses cameras and sensors to build a local 3D point cloud (a map of visual features like table corners and wall textures). A spatial anchor remembers its exact position relative to those physical features. 

  ![](../assets/9a05b6f8eb450be9efa3.png)YouTube·Dilmer Valecillos +2
* Platforms like Meta Horizon OS, Apple visionOS, and Microsoft Azure all use their own variations of Spatial Anchors to ensure that a virtual object (like a digital TV on your wall) stays in the exact same spot across different app sessions. 

  ![](../assets/bd3c43499feb90793a99.png)Niantic Spatial, Inc. +1

### 2. ARCore Cloud Anchors (Google’s Solution)

[ARCore Cloud Anchors](https://developers.google.com/ar/develop/cloud-anchors) are Google's specific implementation of spatial anchors designed for **multi-user and cross-platform (Android & iOS) shared AR experiences**. 

![](../assets/94f7c693955dcc24b6f2.png)Medium·Dean Giddy +1

* **Hosting (Saving the Memory):** When you place a virtual object on a real table, ARCore maps the surrounding physical features and uploads that spatial data to Google’s servers. The cloud endpoint processes it and generates a unique **Cloud Anchor ID**. 

  ![](../assets/84e056109ee463118e21.png)Google for Developers +1
* **Resolving (Recalling the Memory):** You share that ID with a friend. When their phone camera points at the same table, their device downloads the anchor data, matches its local environment with the cloud data, and resolves the anchor. **Boom:** both of you see the exact same virtual object in the exact same physical position. 

  ![](../assets/9a05b6f8eb450be9efa3.png)YouTube·Unity +2
* **Persistence:** Modern implementations of ARCore Cloud Anchors allow these anchors to persist from 1 to 365 days, meaning you can leave a virtual sticky note in a room and find it there months later. 

  ![](../assets/4a40dd1e8e75d8bbddda.png)Google Codelabs

### Spatial Anchors vs. Cloud Anchors

While standard *Spatial Anchors* are often saved **locally** on a single device's memory for a solo user, *Cloud Anchors* use the **internet/cloud** to bridge different devices so multiple people can interact with the same AR layer simultaneously. 

![](../assets/84e056109ee463118e21.png)Google for Developers +3
