### 1. Coordinate Space & Topological Mapping (Double Klein)

A standard Klein bottle requires a 4D embedding to exist without self-intersection. For a 3D raymarching context, we project a **Double Klein Bottle** (a system of two nested, non-orientable topological manifolds) using parametric equations deformed into a distance volume.

Let the base coordinate vector be  $P = \begin{bmatrix} x & y & z \end{bmatrix}^T \in \mathbb{R}^3$ . We lift this vector to a dual-layered coordinate space to handle the "Double" aspect of the geometry:

$P\_{inner}=P\cdot s\_{scale}$   
 $P\_{outer}=P\cdot (1.0-s\_{scale})$

### 2. The Double Hadamard Coordinate Scrambling

To inject the high-frequency deterministic noise and geometric complexity across the distance fields, we apply a **Double Hadamard (H₂)** matrix transformation. A Sylvester-construction Hadamard matrix H₂ scales and orthogonalizes the input domain, scrambling the vectors without destroying continuous distance properties:

$H\_{2}=\frac{1}{\sqrt{2}}\left[\begin{matrix}1&1\\ 1&-1\end{matrix}\right]$

Applying this sequentially to sub-components of our 3D spatial vectors (e.g., mixing the XY and YZ planes) creates a rigid transformation that fractally folds the domain:

$P^{\prime }=\text{Hadamard}(P)\implies \left[\begin{matrix}x^{\prime }\\ y^{\prime }\end{matrix}\right]=\frac{1}{\sqrt{2}}\left[\begin{matrix}x+y\\ x-y\end{matrix}\right]$

By chaining a secondary Hadamard operation (**Double Hadamard**), we maximize coordinate superposition before evaluating the geometric primitives.

### 3. Pinion Rotational Transformation

The mechanical **Pinion** concept is formalized as a continuous, time-dependent rotational matrix  $R\_p(\theta)$  that drives the meshing and winding of the coordinate space, simulating a gearing mechanism acting upon spatial topology:

$R\_{p}(\theta )=\left[\begin{matrix}\cos (\omega t)&-\sin (\omega t)&0\\ \sin (\omega t)&\cos (\omega t)&0\\ 0&0&1\end{matrix}\right]$

The final transformed sampling coordinate for the field evaluation is defined as:   
 $P\_{evaluated}=R\_{p}(\theta )\cdot H\_{2}\cdot H\_{2}\cdot P$

### 4. Mathematical Definition of the Double SDF

A standard SDF returns a single scalar  $d \in \mathbb{R}$ . A **Double Signed Distance Field** evaluates a vector-valued distance field  $\vec{D}(P) = \begin{bmatrix} d\_1 & d\_2 \end{bmatrix}^T$ , keeping track of both independent topological boundaries simultaneously to allow complex CSG (Constructive Solid Geometry) blending, interior rendering, or shell thickness calculations.

$d\_{1}(P)=f\_{\text{Klein}}(P\_{evaluated},r\_{\text{inner}})$   
 $d\_{2}(P)=f\_{\text{Klein}}(P\_{evaluated},r\_{\text{outer}})$

The composited output surface  $f\_{\text{final}}(P)$  utilizes a smooth minimum operator (smin) to merge the dual fields seamlessly:

$f\_{\text{final}}(P)=smin(d\_{1}(P),d\_{2}(P),k)$

### 5. GLSL Raymarching Shader Implementation Blueprint

#version 450 core

layout(location = 0) out vec4 fragColor;
layout(location = 0) in vec2 uv;

uniform float u_time;
uniform vec2 u_resolution;

// Double Hadamard transformation matrix applied to 2D sub-spaces
vec2 doubleHadamard(vec2 p) {
    // Pass 1
    vec2 h1 = vec2(p.x + p.y, p.x - p.y) * 0.70710678118;
    // Pass 2 (Scrambled axes)
    vec2 h2 = vec2(h1.x + h1.y, h1.x - h1.y) * 0.70710678118;
    return h2;
}

// Smooth minimum for seamless blending
float smin(float a, float b, float k) {
    float h = clamp(0.5 + 0.5 * (b - a) / k, 0.0, 1.0);
    return mix(b, a, h) - k * h * (1.0 - h);
}

// Double Signed Distance Field function
vec2 doubleSDF(vec3 p) {
    // Pinion transformation matrix rotation over time
    float theta = u_time * 0.5;
    mat2 rotPinion = mat2(cos(theta), -sin(theta), sin(theta), cos(theta));
    p.xy *= rotPinion;
    
    // Apply Double Hadamard coordinate scrambling
    p.xz = doubleHadamard(p.xz);
    p.yz = doubleHadamard(p.yz);
    
    // Abstracted Klein Bottle math manifold model
    float r1 = 1.2; 
    float r2 = 0.3;
    
    // Layer 1: Inner Shell distance field
    float d1 = length(vec2(length(p.xy) - r1, p.z)) - r2;
    
    // Layer 2: Outer twisted Shell distance field
    float d2 = length(vec2(length(p.yz) - (r1 * 1.3), p.x)) - (r2 * 0.8);
    
    return vec2(d1, d2);
}

void main() {
    vec2 st = (gl_FragCoord.xy * 2.0 - u_resolution.xy) / u_resolution.y;
    
    vec3 ro = vec3(0.0, 0.0, -4.0); // Ray Origin
    vec3 rd = normalize(vec3(st, 1.5)); // Ray Direction
    
    float t = 0.0;
    float maxDist = 20.0;
    vec2 distances = vec2(maxDist);
    
    // Raymarching Loop
    for(int i = 0; i < 128; i++) {
        vec3 p = ro + rd * t;
        distances = doubleSDF(p);
        
        // Composite the fields using smooth minimum
        float d = smin(distances.x, distances.y, 0.2);
        
        if(d < 0.001 || t > maxDist) break;
        t += d;
    }
    
    // Shading based on final surface properties
    if(t < maxDist) {
        vec3 p = ro + rd * t;
        // Simple normal visualization mixed with the internal field differences
        vec3 color = vec3(0.5) + 0.5 * sin(p + vec3(0.0, 2.0, 4.0));
        color *= (distances.x < distances.y) ? vec3(1.0, 0.8, 0.5) : vec3(0.5, 0.8, 1.0);
        fragColor = vec4(color / (1.0 + t*t*0.1), 1.0);
    } else {
        fragColor = vec4(0.0, 0.0, 0.0, 1.0); // Background
    }
}
