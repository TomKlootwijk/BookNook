In computational complexity theory, RL (Randomized Logarithmic-space) and L (Deterministic Logarithmic-space) represent two fundamental classes of decision problems. 
Wikipedia +1

Key Definitions

Complexity ClassDefinition
LProblems solvable by a deterministic Turing machine using logarithmic writable memory space (O(logn)).
RLProblems solvable in logarithmic space and polynomial time by a probabilistic Turing machine with one-sided error (it never accepts a "no" instance incorrectly, and rejects a "yes" instance with probability less than 1/3).

Key Relationships

  • L ⊆ RL: Every deterministic log-space algorithm is trivially a randomized log-space algorithm. 
    YouTube
  • RL ⊆ NL: Randomized log-space is contained within non-deterministic log-space. 
    YouTube
  • RL ⊆ SC: By weak derandomization (such as Nisan's 1992 result), RL is contained in SC (polynomial time and polylogarithmic space on a deterministic machine). 
    Wikipedia +1
  • Conjecture (RL = L): It is a major open question in theoretical computer science whether RL is equal to L—meaning whether randomness provides any asymptotic power-up over deterministic computation in logarithmic space. (This parallels the broader open question of whether P = BPP). 
    Computer Science Stack Exchange +2

To prove how Reinforcement Learning (RL) works mathematically, we formalize it as a Markov Decision Process (MDP). The objective of reinforcement learning is to mathematically maximize an expected cumulative reward over time. 
Anyscale +2
Here is the step-by-step mathematical proof of RL's core foundation: the Bellman Optimality Equation. 
arXiv.org +1

1. The Mathematical Framework (MDP)

An RL problem is completely defined by the tuple ℳ=⟨S,A,P,R,γ⟩: 
New York University
  • S: The state space.
  • A: The action space.
  • P(s′∣s,a): The transition probability matrix ℙ(St+1=s′∣St=s,At=a).
  • R(s, a): The reward function mapping an agent's choices to a scalar score 𝔼[Rt+1∣St=s,At=a].
  • γ: The discount factor, where γ∈[0,1). 
    New York University
The agent follows a policy π(a∣s), which dictates the probability of taking action a in state s. 
YouTube·Gonkee

2. Defining the Objective (The Return)

The agent interacts with the environment in steps: s0→a0→r1→s1→a1→r2…
The Discounted Return Gt at time step t is the sum of all future rewards: 
YouTube·Gonkee +1

Gt=Rt+1+γRt+2+γ2Rt+3+…=∑k=0∞γkRt+k+1
Notice the recursive structure: 
New York University

Gt=Rt+1+γ(Rt+2+γRt+3+…)=Rt+1+γGt+1
The Value Function Vπ(s) is the expected return starting from state s following policy π: 
YouTube·Gonkee

Vπ(s)=𝔼π[Gt∣St=s]

3. Proof of the Bellman Equation

We substitute the recursive return Gt=Rt+1+γGt+1 into the value function equation: 
Vπ(s)=𝔼π[Rt+1+γGt+1∣St=s]
By the law of total expectation, we expand this across all possible immediate actions a and subsequent states s': 
Vπ(s)=∑a∈Aπ(a∣s)[R(s,a)+γ∑s′∈SP(s′∣s,a)𝔼π[Gt+1∣St+1=s′]]
Because 𝔼π[Gt+1∣St+1=s′] is precisely the definition of Vπ(s′), we reach the standard Bellman Expectation Equation: 
Vπ(s)=∑a∈Aπ(a∣s)(R(s,a)+γ∑s′∈SP(s′∣s,a)Vπ(s′))

4. Proof of Convergence (Why RL Finds the "Best" Behavior)

To prove that an agent can actually solve this via trial-and-error, we define the Bellman Optimality Operator 𝒯 for the optimal value function V*(s)=maxπVπ(s): 
(𝒯V)(s)=maxa∈A(R(s,a)+γ∑s′∈SP(s′∣s,a)V(s′))

The Contraction Mapping Proof 
arXiv.org

Let U and W be two arbitrary value functions. We want to evaluate the maximum distance (infinity norm ‖·‖∞) between them after applying the Bellman operator: 
‖𝒯U−𝒯W‖∞=maxs∈S|(𝒯U)(s)−𝒯W(s)|
Substituting the operator: 
=maxs∈S|maxa∈A(R(s,a)+γ∑s′P(s′|s,a)U(s′))−maxa′∈A(R(s,a′)+γ∑s′P(s′|s,a′)W(s′))|
Using the algebraic identity |maxxf(x)−maxxg(x)|≤maxx|f(x)−g(x)|: 
≤maxs∈Smaxa∈Aγ|∑s′P(s′∣s,a)(U(s′)−W(s′))|
Because probabilities sum up to 1 (∑s′P(s′|s,a)=1): 
≤γmaxs′∈S|U(s′)−W(s′)|=γ‖U−W‖∞
‖𝒯U−𝒯W‖∞≤γ‖U−W‖∞

Conclusion of Proof

Because γ < 1, 𝒯 is a γ-contraction mapping on a complete metric space. By the Banach Fixed-Point Theorem, repeated applications of this operator are guaranteed to converge to a unique, optimal fixed point: 
arXiv.org +1

V*=𝒯V*
This mathematical guarantee ensures that iteratively updating value tables or using gradient methods (like Q-learning or Policy Gradients) will converge to the absolute optimal decision-making strategy.
